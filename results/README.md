# Results Directory

This directory stores small outputs that are useful for review and software checks.

- `summaries/`: compact result summaries retained from the manuscript analysis.
- `manuscript/`: selected manuscript-level figures and tables.
- `example_outputs/`: generated by `scripts/run_smoke_test.sh`.

Large intermediate outputs, trained models, scheduler logs, SHAP force-plot HTML files, and full validation plot folders are intentionally excluded from Git.
