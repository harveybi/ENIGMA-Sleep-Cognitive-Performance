# Code Availability

The analysis code is organized for public reviewer access and later archival release.

- GitHub repository placeholder: `https://github.com/<organization>/ENIGMA-Sleep-Cognition`
- Version for submission: `v0.1.0-review`
- Planned archival DOI placeholder: Zenodo DOI to be minted from a tagged GitHub release after manuscript acceptance or at submission if required by the journal.

The repository includes reusable Python modules, analysis scripts, HPC submission templates, synthetic smoke-test data, and selected small summary outputs. Large trained models, scheduler logs, and bulk intermediate result folders are not tracked in Git.

For reproducibility, releases should be created from a clean tag and archived with Zenodo or an equivalent long-term repository. The release notes should state the manuscript version, environment file checksum, and any external data/model archive identifiers.
